# Ray Tracing - Корнуэльская комната

Реализация трассировки лучей для создания сцены "Корнуэльская комната" на C++.

## Требования

- CMake 3.10 или выше
- Компилятор C++17 (g++, clang++ и т.д.)

## Сборка

```bash
mkdir build
cd build
cmake ..
make
```

## Запуск

```bash
./bin/RayTracing
```

Результат будет сохранен в файл `output.ppm` в текущей директории.

## Настройка сцены

Все настройки можно изменить в файле `src/main.cpp`:

### Зеркальность объектов
- `settings.cube_specular` - зеркальность куба
- `settings.sphere_specular` - зеркальность шара

### Прозрачность объектов
- `settings.cube_refraction` - прозрачность куба
- `settings.sphere_refraction` - прозрачность шара

### Зеркальность стен комнаты
- `settings.front_wall_specular` - передняя стена
- `settings.back_wall_specular` - задняя стена
- `settings.left_wall_specular` - левая стена
- `settings.right_wall_specular` - правая стена
- `settings.up_wall_specular` - верхняя стена
- `settings.down_wall_specular` - нижняя стена

### Второй источник света
- `settings.two_lights` - включить/выключить второй источник света
- `settings.light2_position` - позиция второго источника света (x, y, z)

## Структура проекта

```
src/
├── main.cpp              - Точка входа, настройки сцены
├── application.h/cpp      - Основной класс приложения
├── scene.h/cpp            - Управление сценой и объектами
├── ray_tracer.h/cpp       - Алгоритм трассировки лучей
├── geometry/              - Геометрические примитивы
│   ├── point3d.h          - Точка в 3D пространстве
│   ├── vector3d.h          - Вектор в 3D пространстве
│   ├── ray.h               - Луч
│   ├── side.h/cpp          - Сторона фигуры
│   ├── figure.h/cpp        - Базовый класс фигуры (куб)
│   └── sphere.h/cpp        - Сфера
└── graphics/               - Графические компоненты
    ├── color.h             - Цвет
    ├── material.h          - Материал объекта
    ├── light.h             - Источник света
    └── camera.h             - Камера
└── utils/                  - Утилиты
    ├── image_writer.h/cpp  - Запись изображений
    └── math_utils.h        - Математические константы
```

## Реализованные функции

✅ Корнуэльская комната (большой куб со всеми гранями)
✅ Минимум 1 объект (непрозрачный, неотражающий) - куб или шар
✅ 2-й объект того же вида
✅ Дополнительные объекты другого вида (шар и куб)
✅ Зеркальное отражение для объектов (куб и шар) с возможностью включать/выключать
✅ Прозрачность для объектов (куб и шар) с возможностью включать/выключать
✅ Зеркальная стена комнаты с возможностью выбора стены
✅ Дополнительный источник света с возможностью изменения позиции

## Пример использования

```cpp
SceneSettings settings;
settings.cube_specular = true;        // Включить зеркальность куба
settings.sphere_refraction = true;    // Включить прозрачность шара
settings.front_wall_specular = true;  // Сделать переднюю стену зеркальной
settings.two_lights = true;           // Включить второй источник света
settings.light2_position = Point3D(0.0f, 4.0f, 4.9f);  // Позиция второго света

app.setSettings(settings);
app.run();
```

## Формат вывода

Изображение сохраняется в формате PPM (Portable Pixmap), который можно открыть в большинстве графических редакторов или конвертировать в другие форматы.
