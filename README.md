# Ray Tracing - Корнуэльская комната

Реализация трассировки лучей для создания сцены "Корнуэльская комната" на C++.

## GUI на SFML

Теперь приложение открывает окно SFML с интерактивными настройками сцены:
- F1/F2 — включить зеркальность куба/шара.
- F3/F4 — включить прозрачность куба/шара.
- 1–6 — переключить зеркальность стен (front/back/left/right/top/bottom).
- L — включить второй источник света.
- Стрелки + PgUp/PgDn — двигать второй источник света (Shift для ускорения).
- R — пересчитать сцену с текущими параметрами.
- S — сохранить текущее изображение в `output.ppm`.
- Esc — выход.

### Сборка
Нужен установленный SFML 2.5+:
```bash
sudo apt install libsfml-dev   # или соберите SFML вручную
mkdir -p build && cd build
cmake ..
cmake --build .
./bin/RayTracing
```
